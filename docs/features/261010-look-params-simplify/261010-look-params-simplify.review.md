# 检视报告

## 概要

本次改动针对视向参数系统进行了精简与关键算法重构。移除了 3D 空间变换、眉毛联动与眼球形变联动，修正了 `mixLookChannel` 将增益作为归一化混合权重导致单源在线时绝对值被约掉的缺陷，拆分了头身与眼球的独立控制增益，调整了默认值并升级了配置存储版本（v1 → v2）。整体架构清晰、契约同步严密、测试覆盖针对性强，无阻塞问题。

## 需求对齐

完全满足需求，未见遗漏与过度设计：
1. **删除冗余联动**：彻底移除了 `3D 空间变换`（含 `compute3dTransform`、`Transform3dResult` 及 `view.tsx` 舞台 CSS perspective 写入）、`眉毛上下联动`（`browGain`）、`眼球形变联动`（`eyeBallFormGain`）。
2. **位移增益默认 -2**：`camPanGain` 与 `gyroPanGain` 默认值调整为 `-2`，滑条范围同步放宽至 `-3..3`。
3. **独立眼球系数**：将原视线/陀螺仪转向共用的 `camAngleGain`/`gyroAngleGain` 拆分出独立的 `camEyeGain`/`gyroEyeGain`，在 `model.ts` 中单独驱动眼球。
4. **增益语义修正**：`mixLookChannel` 重构为「输入 × 增益」带符号振幅直接相加并截断至 ±1，解决了 `0.005` 与 `0.1` 无差异的缺陷；HUD 中新增 `trimNumber` 保证自适应小数展示精度，避免 `0.005` 被截断显示为 `0.01`。
5. **配套契约**：存储键升版至 `lv-look-params-v2`，第三人称对视停用集合纳入眼球增益，文档、测试用例与 AGENTS.md pitfall 说明均已同步更新。
