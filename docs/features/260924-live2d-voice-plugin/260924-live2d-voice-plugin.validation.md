# dsh-live2d-voice 用户验证要求

## 验证说明

- 验证环境：线上 DSH Web GUI（插件安装 + 重启后）；桌面或手机浏览器（语音输入需 HTTPS 或 localhost 才有麦克风权限；桌面需 WebGL）
- Phase 1（Live2D 舞台 + TTS + 字幕）：自动化 e2e 21/21（`e2e/verify-live.mjs`），真机感官项待验
- Phase 2（连续语音输入 v0.2.0）：自动化 e2e 17/17（`e2e/verify-voice.mjs`，同 context 假麦克风注入——容器无音频硬件），**真实麦克风的拾音质量、回声特性、VAD 阈值手感只能在真机确认**
- 前置：`~/.dsh/live2d-voice.json` 配置 `apiKeyFile`（Fish TTS）、`asrCredentialsFile`（火山 ASR）、`modelPath`（haru 已就位）
