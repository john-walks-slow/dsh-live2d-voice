# 灵动视线/自然行为（lively-gaze Phase 1）用户验证

## 验证说明

- 验证对象：角色的"活眼神"新行为——互视节奏（不再死盯用户）、说话/倾听/思考注视率、头身微动（点头/歪头/呼吸轻摆/重心微摆/扫视）、无摄像头待机眼神；以及两条硬要求：**整个新行为可一键关闭**、**实验参数足够多可调**。
- 环境/前置条件：
  - 真实设备浏览器进入 Live2D 视图（HUD ⚙ 面板、系统设置均可操作）；
  - 摄像头权限（验证互视节奏时开启「视线追踪」）；无摄像头也能验证待机眼神；
  - 语音/文本对话可正常进行（验证说话/倾听节奏时）。
- 自动化已覆盖：行为状态机单测 8/8、e2e 10/10（配置面、行为活性 dataset.lvGaze、总开关关闭后行为消失、HUD 总开关 UI）。以下为**必须实机感受**的项。
