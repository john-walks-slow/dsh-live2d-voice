# enhanced-gaze-tracking 用户验证

## 验证说明

- 验证对象：增强视线与陀螺仪跟踪系统（转头小幅度化、不限范围手输调试、3D transform 空间透视、视线中心手动/一键自动校准、扩展可动性联动）
- 环境/前置条件：移动端或桌面浏览器打开 Live2D 页面，允许前置摄像头权限

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 1. 开启前置摄像头视线跟踪，轻微移动视线与眼球 | 头部转动自然收敛、不再剧烈晃脑；视线移动主要由眼球和身体微动配合承载（默认角度上限调至 8°） | | 待验证 | |
| 2. 打开 HUD ⚙ 快捷设置 → 视向灵敏度 → 展开“详细参数”，在任意参数的数字输入框中输入超出滑块范围的数值（如 `50` 或 `-3.5`） | 输入负数、小数正常生效且不被重置覆盖，模型响应手输的极限参数，滑块停靠在端点 | | 待验证 | |
| 3. 在“详细参数”中查看“3D 空间变换”并微调 3D透视角度、视线/陀螺仪 3D 增益 | 舞台/画布产生基于 perspective 的 3D 倾斜（rotateX/Y/Z）透视空间感；归零后平滑恢复正平面 | | 待验证 | |
| 4. 开启视线追踪，在“体感实验”下点击“设当前为中心”，或手动输入/拖动水平中心 X 与垂直中心 Y | 点击“设当前为中心”后，当前视线状态被锁定为正中 (0, 0)；手动修改偏移值能补偿摄像头偏上或打孔屏偏移 | | 待验证 | |
| 5. 观察头部侧倾（Roll）与上下看（Pitch）时的连带动效 | 头部侧倾时身体 Z 轴伴随微侧倾 (ParamBodyAngleZ)；上下看时眉毛伴随轻微挑落 (ParamBrowLY/RY)；视线偏角时眼球形态微动 (ParamEyeBallForm) | | 待验证 | |
