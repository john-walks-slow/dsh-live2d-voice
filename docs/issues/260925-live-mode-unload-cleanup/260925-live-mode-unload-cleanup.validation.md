# Live 模式卸载与资源释放用户验证要求 (Validation)

## 验证目的
确认用户在以下场景下：
1. 切出 Live 模式（点击退出 Live、切换到 Chat Tab）；
2. 切换到其他会话（在 DSH 侧边栏选择不同 Session）；
3. 手机切到后台（切到其他 App、锁屏、浏览器切其他标签页）；
4. 麦克风录音立即停止、语音播放立即停止、摄像头与陀螺仪停止、WebGL 显存释放、服务端任务终止，无任何后台串音或意外收音。

## 场景用例清单

| 用例编号 | 场景 | 操作步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| TC-01 | 切出会话 | 在 Session A 开启 Live 模式，正在播放语音或正在录音，在侧栏点击切换到 Session B | Session A 的所有语音播放、录音、TTS 立即停止，控制台无残留报错，Session B 干净展示 |
| TC-02 | HUD 退出 Live | 在全屏或常规 Live 态，点击 HUD 上的「退出 Live」按钮 | 麦克风停止录音，页面平滑切回 Chat Tab，Live 资源与 WebGL 完全卸载 |
| TC-03 | 页面切后台 / 锁屏 | 在 Live 态开启麦克风，将手机锁屏或切换到微信 | 麦克风停止采音，讲话不再被识别和上传给 AI，后台不发出任何声音 |
| TC-04 | 页面切回前台 | 从后台切回浏览器 | 状态合理恢复，麦克风不擅自偷听，若之前开启则恢复为待机或正常监听状态 |
| TC-05 | 显存与内存释放 | 离开 Live 模式后检查 WebGL 上下文与内存占用 | WebGL Context 触发 loseContext，纹理与 Application 被完全 destroy，无内存泄漏 |
| TC-06 | 连续切入切出 | 在 Live 和 Chat 之间快速切换 5 次以上 | 无音频 Context 耗尽报错（Max AudioContexts limit），无残存声音重叠 |
