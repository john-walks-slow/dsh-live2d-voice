# voice-translation-dup 用户验证

## 验证说明

- 验证对象：dsh-live2d-voice 三个用户报告 bug 的修复——翻译缺尾/堆首行、流式语音双发、独立页字幕双显。
- 环境/前置条件：线上 4180（需先部署本次修复）；真实麦克风；开启字幕翻译（设置中 subtitleLanguage ≠ off）；ASR 模式可切换（流式/非流式）。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| **翻译填充**：开启翻译后，对角色说一句较长的话（触发 3 句以上回复），观察每句字幕的翻译行。 | 每句 assistant 字幕下方都出现对应翻译，不再"全堆第一句"或"后面几句无翻译"。 | | 待验证 | |
| **翻译不缺尾**：连续对话几轮，留意每轮最后一句字幕。 | 每轮尾句都有翻译，不再"最后一句翻译丢失"。 | | 待验证 | |
| **流式单发**：ASR 切到流式模式，说一句话，观察消息历史。 | 消息历史只新增一轮（一条用户消息 + 一条 AI 回复），不再"发送两回"。 | | 待验证 | |
| **独立页单卡**：在独立页（/live2d-voice/app）打字输入一句话，观察用户字幕。 | 用户输入的文字只显示一张字幕卡，不再"重复两遍"。 | | 待验证 | |
| **翻译速度感知**：留意翻译出现时机。 | 翻译在对应句子说完后数秒内出现；若会话模型为思考模型（reasoner），翻译会明显偏慢——此为已知限制（复用会话模型），非 bug。 | | 待验证 | 若仍觉得慢，可后续为翻译配置专用快速模型。 |

## 验证结论

待验证。

## 待跟进

- 翻译超时上限为 20s，与字幕寿命（21s）接近：极慢翻译可能赶不上目标字幕行（翻译到时该行已被清扫）。若用户感知到"翻译时有时无"，可收紧超时或改用快速模型。
